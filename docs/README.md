# Fixed-Size Memory Pool Allocator Docs

This folder separates project knowledge by concern:

- `architecture.md`: system design, invariants, and tradeoffs.
- `data-flow.md`: how allocation and deallocation move through the buffer and free list.
- `terminology.md`: allocator terms and examples.
- `resources.md`: reference links for C++ style, CMake, sanitizers, and benchmark tooling.
